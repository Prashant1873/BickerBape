## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding, subtle borders |
| sm | 8px | Compact chip padding, inner skeleton gaps |
| md | 16px | Default card padding, grid spacing |
| lg | 24px | Section padding, container gaps |
| xl | 32px | Layout spacing between primary panels |
| 2xl | 48px | Major dashboard block separation |
| 3xl | 64px | Page-level top/bottom whitespace |

Exceptions:
- 44px minimum touch target for interactive controls and pagination buttons (Fitts's Law compliance)
- 52px table row height for dense financial data rows
- 116px fixed card height for SimSim summary metric cards
- 224px fixed card height for screener fund card skeletons (matching real card dimensions)
- 380px fixed container height for SimSim trajectory chart canvas skeleton

- Animation: Synchronized CSS `@keyframes shimmerSweep` across 1.6s duration with linear easing

## Visuals & Layout Hierarchy

1. **Primary Visual Anchor (Screener)**:
   - Primary Anchor: Screener Results Counter & Active Filters Bar (`Showing {N} of {Total} Schemes`).
   - Secondary Anchor: Scheme Card Grid or Scheme Table rows with SmartScore™ badges.
2. **Primary Visual Anchor (SimSim Workspace)**:
   - Primary Anchor: Simulated Present Value KPI card (`₹{presentValue}`).
   - Secondary Anchor: Compounded Portfolio Trajectory Line Chart canvas (`h-80 w-full`).
3. **Atomic Loading Barrier Contract**:
   - Initial application state remains behind an atomic mounting gate (`isPrimed: boolean`).
   - Skeletons render synchronously across all layout slots with exact primed dimensions (CLS = 0).
   - Once all AMFI datasets and categories are parsed, a synchronized 240ms crossfade reveals all layout elements together without piecemeal flashing.
